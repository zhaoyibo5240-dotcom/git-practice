# 我的第一个 GitHub 仓库

这是我的练习项目，用来学习 Git 和 GitHub 的基本操作。

## 学到了什么

- [ ] 安装 Git
- [ ] 注册 GitHub 账号
- [ ] 创建本地仓库 `git init`
- [ ] 提交代码 `git add` + `git commit`
- [ ] 推送到 GitHub `git push`

## 常用命令

```bash
git status            # 看当前状态
git add .             # 把所有改动加入暂存区
git commit -m "说明"  # 提交，生成一个历史版本
git push              # 推到 GitHub
git pull              # 从 GitHub 拉取最新
git log --oneline     # 看提交历史
```
